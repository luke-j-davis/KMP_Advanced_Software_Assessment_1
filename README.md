# String Matching Algorithm Comparison

The program is split into three different algorithms:

* KMP
* Naive
* My Algorithm

## How to Run

### Requirements

* Windows operating system
* C++ compiler
* MinGW/G++ or another C++ compiler

### Compile

From the project directory, run: This is to get all the files properly connected.

```bash
g++ main.cpp KMP.cpp MyAlgorithm.cpp Naive.cpp Tests.cpp -o program
```

### Run

```bash
./program
```

The program runs the test cases for all three algorithms and records the results in a CSV file called `results.csv`.


### The Comparison

It is being compared on memory and Speed.
